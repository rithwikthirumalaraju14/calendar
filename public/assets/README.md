# Local visual assets

`moon.jpg` is the lunar surface map used by the reference Night Garden project:
https://threejs.org/examples/textures/planets/moon_1024.jpg

The moon is projected with the adapted `src/lunar-surface.js` renderer from
`tree-season-recovered/final_one/lunar-surface.js` and shaded with CSS.

Fonts are bundled locally from Fontsource. Cormorant Garamond and Plus Jakarta Sans
are distributed under the SIL Open Font License (see their installed packages).

The ghost rig, mood poses, costumes, and doorway in `src/stickers/` are adapted
from the user's `neww/stickeranimation idea` project (`index.html`, `styles.css`,
`app.js`, `entrance.js`, and the silhouette in `ghost-sticker.svg`). The lettering
and messages have been personalized as `deyam`. The app icon uses the same ghost.
